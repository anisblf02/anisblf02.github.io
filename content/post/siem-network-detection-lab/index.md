A lab where network traffic becomes searchable security data.

- Deployed Elasticsearch, Kibana and Elastic Agent.
- Integrated Zeek to ingest conn, dns, http and ssl logs.
- Built KQL dashboards and SIEM detection rules to surface suspicious network activity.
- Wrote 5 custom Zeek detection scripts.
